# Churn-Analysis-and-Customer-Intelligence
What I Did in This Project
Extracted Relational Data: Pulled customer demographics, subscription details, and support tickets directly from a database.
Cleaned & Standardized Datasets: Handled missing values, renamed columns, dropped irrelevant fields, and formatted data for consistency.
Merged Multi-Table Insights: Joined customer, subscription, and support data to create a unified view of user behavior.
Analyzed Retention & Churn: Evaluated cancellation reasons, calculated churn rates across subscription plans, and tracked support ticket escalations.
Generated Summary Metrics: Created pivot tables and aggregations to measure Customer Lifetime Value (CLTV), monthly charges, and churn risk.
Tech Stack: Python (Pandas, NumPy, Matplotlib, Seaborn) & MySQL database integration.
